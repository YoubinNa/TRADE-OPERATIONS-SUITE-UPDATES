# Master / User v0.1.61 Beta

- Master/User v0.1.61 공동 업데이트입니다. 승인된 조회·공유 전송량 개선과 PSR R51 VN/KR 업데이트(R52 완료·보류 문서 기준)를 함께 통합했습니다.
- 원재료·완제품 기본정보는 화면과 법인을 선택한 때 필요한 자료만 조회하고, 보이는 동안 60초 확인을 유지합니다. 과부족 현황판은 법인 선택 및 새로 확인으로 갱신하며 원본 Excel 다운로드와 오프라인 HTML을 유지합니다.
- 변경 없는 검증 완료 공유 파일은 재전송하지 않습니다. 새 파일의 실제 다운로드 검증, 서버 Master 권한 확인, 원자적 게시와 기존 승인·원본·업무 결과를 유지합니다. 메인 수책재고 상태 조회를 통합하고 Validation 화면 확인 간격은 60초로 조정했습니다.
- 운영 조회 파일의 전체 조회 결과와 SHA-256 일치 및 파일별 HTTP 응답 본문 96.43~98.41% 감소를 확인했습니다. 기존 모듈의 업무 엔진, 로그인·공유·작업 보호를 유지하며 Master/User 두 업데이트 ZIP을 제공합니다.
