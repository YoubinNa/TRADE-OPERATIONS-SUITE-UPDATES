# Master / User v0.1.55 Beta

- Master/User v0.1.55 공동 업데이트입니다. 과부족 현황 HTML 다운로드의 명칭과 버튼 배치를 정리하고 양사 배포 HTML 상단을 법인명·영문명 / 자료 기준으로 간소화합니다.
- 출하가능수량 / 원재료·완제품 정보 순서로 모듈명과 기능 카드·탭을 정리합니다. 법인을 먼저 선택한 뒤 기능을 사용할 수 있습니다.
- 두 현황판 법인 버튼의 배경 음영·테두리를 강조하며, 비활성 기능 카드도 선명한 테두리를 유지합니다. Master/User UI와 기존 연결·작업 보호·계산 기준을 보존합니다.
- 기존 설정·저장 인증·캐시·업무자료를 보존하며 적용 후 재시작합니다. Master/User 공동 온라인 업데이트이며 별도 Setup은 제공하지 않습니다.
