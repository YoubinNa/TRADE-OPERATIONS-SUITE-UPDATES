# Master / User v0.1.37 Beta

- Master/User v0.1.37 Beta를 같은 앱·8개 모듈·업무 기준의 한 배포 단위로 제공합니다.
- PSR 계산기에 승인 원천 6c88820의 최신 KR/VN 기능과 완료 기준을 반영했습니다. 기존 계산 의미와 미완료 보류는 유지합니다.
- Balance Sheet vs Customs Data의 IMPORT/EXPORT 업로드를 한 Excel 파일로 통합했습니다. Balance Sheet 파일은 별도로 선택합니다.
- AMOVINA 및 AMOGREEN VINA 수책재고취합에 최종 취합 파일만으로 과부족 현황을 확인하고 Excel 보고서를 저장하는 기능을 추가했습니다.
- 전체 Glass Workspace UI, 기존 재고취합 계산 코어, 다른 4개 모듈과 Master/User 권한 차이는 유지합니다.
- 내장 보고서 양식의 이전 예시값과 불필요한 메타데이터를 정리하고 실제 출력 값·수식·서식의 원본 일치를 확인했습니다.
- 두 업데이트 ZIP과 두 단일 Setup을 한 서명 요청으로 연결합니다. 서명 전달 후 양쪽 검증을 통과해야 한 목록으로 활성화합니다.
- 실제 Windows 설치·재설치·파일 선택/저장·v36에서 적용/복구를 검증했습니다. 사용자 PC 적용과 Microsoft Excel 자체 표시/재계산은 별도입니다.
