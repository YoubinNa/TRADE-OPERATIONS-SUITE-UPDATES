# Master v0.1.19

기존 Master v0.1.17에서 프로그램 내 온라인 업데이트로 적용합니다. 최초 설치용 Setup과 User 배포본은 아닙니다.

- 개인 메일 주소·양식·서명 이미지를 공개 패키지에서 제외하고 기존 PC의 필수 메일 자료를 로컬에 보존합니다.
- 번역 참고 예문의 실제 식별값을 가상 값으로 표시했습니다. 번역 기능·확정 용어·비차단 알림은 유지합니다.
- GitHub 로그인·토큰 없이 서명된 목록 확인 및 다운로드·적용이 가능합니다.
- 실제 Master 서명 및 Windows 적용·복구·자료 보존 검증을 통과했습니다. 사용자 PC 적용 확인은 별도입니다.

포함된 제3자 구성요소에는 패키지의 해당 라이선스가 적용됩니다.
