# Master v0.1.19 — 공개 업데이트 검증 후보

이 파일은 기존 Master v0.1.17용 업데이트 검증 후보입니다. 활성 stable 목록은 v0.1.17을 유지하며, 서명·적용 검증 전에는 정식 업데이트로 표시하지 않습니다. 최초 설치용 Setup이나 User 배포본이 아닙니다.

- 개인 메일 주소·양식·서명 이미지를 공개 패키지에서 제외했습니다. 기존 PC의 필수 메일 자료는 로컬에 보존합니다.
- 번역 참고 예문의 실제 식별값을 가상 값으로 표시했습니다. 번역 기능과 확정 용어는 유지합니다.
- 일반 사용자의 로그인·GitHub 토큰 입력 없이 업데이트를 제공하는 공개 채널 검증용입니다.

포함된 제3자 구성요소에는 패키지의 해당 라이선스가 적용됩니다.
