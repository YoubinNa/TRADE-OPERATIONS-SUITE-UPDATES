# Master / User v0.1.54 Beta

- Master/User v0.1.54 공동 업데이트입니다. 법인별 수책재고 과부족 현황의 결과를 HTML로 저장하고 오프라인에서 열 수 있습니다.
- 현황판에 원재료·완제품 정보 / 출하가능수량 모듈을 추가합니다. 양사 최신 공유 기본정보 조회, Balance sheet 업로드, 제품 검색·출하 및 추가 수입 시뮬레이션·Excel 저장을 지원합니다.
- Master 화면은 기존 설명을 유지하고 User 화면은 불필요한 자료 연결·원천 설명을 줄여 기능 중심으로 표시합니다. 최신 확인 상태와 오류·계산 경고는 유지합니다.
- 업데이트 승인 패키지 비교 오류를 수정했습니다. 기존 업무 계산·설정·저장 인증·캐시·업무자료를 보존하며 적용 후 재시작합니다. 별도 Setup은 제공하지 않습니다.
