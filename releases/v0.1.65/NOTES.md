# Master / User v0.1.65 Beta

- Master/User v0.1.65 공동 업데이트입니다. 공통 업무 메뉴와 실행 중 작업 탭을 적용했습니다.
- 현황판·업무 카테고리·업무 도구를 같은 단계로 표시합니다. 메뉴는 기본 고정이며 숨기면 왼쪽 압정으로 즉시 복원할 수 있습니다.
- 상단은 업무 메뉴 → 강조된 메인화면 → 작업 탭 개수 → 모듈 탭 순서입니다. 모듈·홈 이동 시 입력·선택 파일·계산 결과를 유지하고 같은 모듈은 한 탭으로 엽니다.
- ×로 닫으면 해당 작업을 종료합니다. 프로그램 종료·업데이트는 숨겨진 탭까지 확인합니다. 프로그램 종료 후에는 탭이 복원되지 않으므로 필요한 결과를 저장하세요.
- 기존 업무 엔진·계산·판정·권한·파일 검증·조회 전송량 개선과 설정·결과·저장 인증·캐시 보존을 유지합니다.
