# Master / User v0.1.99 Beta

- 검증 현황과 확인 요청 메일 발송 현황을 현황판의 별도 카드로 이동했습니다. 어느 상태를 선택해도 두 법인을 함께 표시합니다.
- 현황판은 3열·2행으로 정리했고 업무 도구 6개는 넓은 화면에서 한 행에 표시합니다. 좁은 화면에서는 자동으로 줄을 나눕니다.
- 완료는 녹색, 미완료는 빨간색입니다. 메일 완료 기준은 Outlook의 발송 요청 접수이며 수신 확인을 뜻하지 않습니다.
- Master/User 공동 업데이트입니다. 기존 메일 v0.7.8과 설비 v0.31, 설정·인증·즐겨찾기·업무 자료를 유지합니다.
