# Master / User v0.1.59 Beta

- Master/User v0.1.59 공동 업데이트입니다. 아모비나 REVIEW24와 아모그린비나 1.0.10 승인본의 창고 담당 시트 선택 기능을 반영했습니다.
- 업로드 시 가용 담당 시트를 기본 전체 선택하고 개별·전체 선택/해제를 지원합니다. 전체 해제한 파일은 이번 실행에서 제외하며, 유효 입력이 없으면 실행을 막습니다. 파일 교체 시 선택을 초기화하고 누락된 시트는 비활성화합니다.
- 아모비나는 공유 창고 시트의 해당 담당자 영역과 반영 이력을 검증하고 다른 담당자 자료를 보존합니다. 아모그린비나는 기존 법인별 담당 시트 범위를 유지하며 누락·숨김 시트를 제외합니다.
- v0.1.58의 출하가능수량·Maximum 예외 3가지와 근거 팝업, PSR R32, 로그인·공유·권한·작업 보호를 유지합니다. 설정·저장 인증·캐시·업무자료를 보존하며, 업데이트 후 재시작하고 별도 Setup은 제공하지 않습니다.
