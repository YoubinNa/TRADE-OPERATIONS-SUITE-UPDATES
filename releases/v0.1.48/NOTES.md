# Master / User v0.1.48 Beta

- Master/User v0.1.48 Beta 공동 업데이트입니다. 양사 최신 재고 모듈과 공통 화면을 함께 적용합니다.
- 업무기록·검증결과 HTML·재고 원본의 공유 저장소를 Supabase로 전환합니다. User는 업데이트만으로 자동 연결되며 별도 로그인·연결 파일·인증키 입력이 필요 없습니다.
- Master의 최초 인증에서 보호 저장한 연결을 재사용합니다. 재고 등록·승인은 Master만, 기록 저장·조회와 승인된 원본 다운로드는 Master/User 모두 가능합니다.
- 회사별 최신 자료를 제공하고 최종 취합·과부족 파일은 각각 원본 그대로 저장·다운로드합니다. 기존 저장소 자료는 자동 이관 완료로 간주하지 않으며 필요한 최신본을 등록합니다.
- 동일 자료는 캐시로 재사용하고 최신본·30일 미사용·PC당200MB·중단 임시파일24시간 기준으로 정리합니다. 사용자가 저장한 파일·원본·미전송자료·인증정보는 보호합니다.
- 기존 설정·업무 결과·보호 인증·캐시를 업데이트와 복구에서 보존합니다. 적용 후 재시작하며 별도 Setup은 제공하지 않습니다.
