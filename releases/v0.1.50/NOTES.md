# Master / User v0.1.50 Beta

- Master/User v0.1.50 공동 업데이트입니다. 현황판에 법인별 수책재고 과부족 현황을 추가합니다.
- 현황판은 기존 Master 등록 자료와 저장소 연결을 사용합니다. 상세 현황과 승인 요약에 각각 원천 버전·해시를 표시합니다.
- 열린 현황판은 60초 주기와 창 복귀 시 최신 자료를 확인합니다. 연결 실패 시 마지막 자료와 확인 불가 상태를 표시하며, 다운로드는 표시된 원본과 일치할 때 진행합니다.
- Validation 회사명은 AMOVINA 빨간색·AMOGREEN VINA 초록색으로 표시하고, 양사 재고 카드 문구를 과부족 현황판으로 변경합니다.
- 현황판 카테고리는 한 줄 3칸 중 법인별 현황만 활성화하고 나머지 두 칸은 공란으로 둡니다. 기존 양사 재고 서식 업데이트와 업무 계산은 유지합니다.
- 기존 설정·업무자료·보호 인증·캐시를 보존합니다. 업데이트 후 재시작합니다. 실제 PC 간 파일 교체 반영은 배포 후 확인하며 별도 Setup은 제공하지 않습니다.
