# Master v0.1.23 — 메일 설정 재실행 오류 수정

v0.1.22에서 프로그램 재실행 후 기존 개인 메일 설정을 잘못 거부할 수 있는 비교 오류를 수정했습니다. 이름·주소·선택값과 수신자 순서를 직접 비교하며 기존 개인 파일은 다시 작성하지 않습니다.

Glass UI·배율·회사별 제목·승인 참조처 정책·업무 모듈과 결과 저장 기능을 유지합니다. Windows의 별도 프로세스 재실행·설정 보존·변조 거부 검사와, 기존 Master 운영 서명에 대한 실제 v0.1.22/v0.1.23 실행파일의 무인증 다운로드·적용·복구 검증을 통과했습니다.

Master 장기 업데이트 목록 순번 8로 제공합니다. 앱에서 최신 여부 확인 → 다운로드 → 적용·재시작으로 진행합니다. 기존 v0.1.20 이하의 전환 목록은 v0.1.22 / 순번 6으로 유지하며 장기 채널 전환 후 v0.1.23을 받습니다. 장기 목록의 만료는 2099-12-31 23:59:59 UTC입니다.

사용자 PC는 v0.1.22 적용·UI 확인 및 메일 설정 로딩 오류까지 확인됐습니다. v0.1.23의 실제 PC 적용·완전 종료 후 재실행·메일 미리보기 확인은 남아 있습니다. 시험을 위한 실제 메일 발송은 필요하지 않습니다.

공개 파일에는 개인 메일 주소·양식·서명 이미지·개인키가 포함되지 않습니다. User 정식 배포는 별도입니다. 이미 게시된 v0.1.23 ZIP은 재빌드하거나 교체하지 않았습니다.

게시 후 Windows 실제 v0.1.22/v0.1.23에서 공개 활성 목록 HTTP 200·정확한 서명 바이트·무인증 전체 다운로드·서명된 적용/복구를 추가 확인했습니다. 사용자 PC 확인 상태는 위와 같습니다.
