# Master v0.1.23 — 메일 설정 재실행 오류 수정 후보

v0.1.22에서 프로그램 재실행 후 기존 개인 메일 설정을 잘못 거부할 수 있는 비교 오류를 수정했습니다. 이름·주소·선택값과 수신자 순서를 직접 비교하며 기존 개인 파일은 다시 작성하지 않습니다.

Glass UI·배율·회사별 제목·승인 참조처 정책·업무 모듈과 결과 저장 기능을 유지합니다. 실제 Windows의 별도 프로세스 재실행·설정 보존·변조 거부·업데이트 적용/복귀 검사를 통과했습니다.

이 Release는 서명 준비용 후보이며 활성 업데이트 목록은 v0.1.22로 유지합니다. Master 운영 서명 검증 후 장기 목록으로 활성화합니다. 사용자 PC의 수정 확인과 실제 Outlook 송수신은 별도이며 시험을 위한 메일 발송은 하지 않았습니다.

공개 파일에는 개인 메일 주소·양식·서명 이미지·개인키가 포함되지 않습니다. User 정식 배포는 별도입니다.

후보 파일의 공개 게시 및 무인증 전체 다운로드·SHA-256 확인을 완료했습니다. 기존 v22와 새 v23 Windows 실행파일의 실제 다운로드 검사도 통과했습니다. 장기 목록 한 번 서명을 준비하며 아직 활성화하지 않았습니다.
