# Master v0.1.30

업무 도구 Glass UI 통일, 세관 검수비용의 ‘세관 제시 금액’ 표시, 승인된 PSR VN/KR 계산기 활성화, 서명된 누적 업데이트 개선을 한 파일에 포함합니다. 기존 번역 및 검증·재고 기준은 유지합니다.

## 적용 방법

1. Master Signing 도우미에서 v0.1.30 요청에 승인·서명·전달합니다.
2. [자동 게시 상태](https://github.com/YoubinNa/TRADE-OPERATIONS-SUITE-UPDATES/blob/main/publisher/status.json)가 v0.1.30 / completed인지 확인합니다. 대화의 완료 보고는 필요 없습니다.
3. 이 Release의 Master ZIP을 내려받습니다. 압축을 풀지 않습니다.
4. 사용 중인 프로그램에서 결과를 저장하고 **업데이트 → 업데이트 파일 가져오기**에서 ZIP을 선택합니다. 변경 내용을 확인하여 적용합니다.
5. 프로그램이 다시 열리면 v0.1.30을 확인합니다. 필요한 구성 요소 갱신 안내를 따릅니다.

기존 v22~v27의 온라인 목록 판독기는 신규 모듈을 거부하므로 최초 한 번 가져오기가 필요합니다. 중간 버전 설치나 새 Setup 재설치는 필요하지 않습니다. 개선된 v30 이후에는 호환되는 서명 누적 업데이트를 온라인으로 적용합니다. 이 파일은 Master용이며 User 정식 배포와 별개입니다.

기존 통합 기준: 번역 v0.1.0(입력/실행 연결 오류 복구 포함), Balance vs ECUSS v0.7.6, Balance Sheet 검증 28.2, AMOVINA REVIEW18, AMOGREEN VINA V1.0.3. 개별 프로젝트의 후속 수정본은 별도 통합 요청·검증 대상입니다.
