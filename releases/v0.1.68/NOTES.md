# Master / User v0.1.68 Beta

- Master/User v0.1.68 공동 업데이트입니다. 아모비나·아모그린비나 수책재고 취합과 PSR 계산기 개선을 함께 반영했습니다.
- 아모비나는 지원 공정·창고의 불필요한 조건부 서식·메모·개체를 정리하고 코드 중복 표시를 단일 규칙으로 유지합니다. 재고 시트 서식·개체 정리 전용 기능도 사용할 수 있습니다.
- 아모그린비나는 선택한 공정·창고 원천의 불필요한 서식·메모·개체를 제외하고 창고 코드와 LIQUIDATION TOTAL의 중복 표시 규칙을 정리합니다. 회사별 기존 제외·보존 기준을 유지합니다.
- PSR BOM 업로드는 A~F열만 읽습니다. G열 이후의 수식·메모·오류 및 추가 열만 있는 행은 무시하며 기존 필수값·최대 2,000행 검증을 유지합니다.
- 기존 계산·협정별 확인/보류·결과 Excel과 공통 작업 탭, 권한, 설정·인증·저장 자료 및 업데이트 복구 기능을 유지합니다.
