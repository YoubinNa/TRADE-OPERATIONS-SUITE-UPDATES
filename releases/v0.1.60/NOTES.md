# Master / User v0.1.60 Beta

- Master/User v0.1.60 공동 업데이트입니다. 아모비나 REVIEW25와 아모그린비나 v1.0.11의 정상 담당자 수정 반영 및 변경 셀 상세 기능을 통합했습니다.
- 아모비나는 원천 반영 이력이 손상되거나 불일치해도 정상 기준파일 이력과 다른 담당자 코드 순서·구분 행으로 담당 영역을 확정할 수 있으면 반영하고 특이사항을 안내합니다. 다른 담당자 자료를 보존하며 영역이 불명확하면 임의 복사하지 않습니다.
- 아모그린비나는 기존 전용 시트 반영을 유지합니다. 담당자·시트·변경 유형·기준/원천/결과 셀과 값·수식 및 이력 대조 상태를 상세표와 전체 JSON 처리기록에 표시합니다. 내부 이력 문제와 원천 데이터 오류를 구분합니다.
- 기존 창고 시트 선택, 과부족, 서식·NG SUM·시트 순서, 출하가능수량·Maximum·팝업, PSR R32 및 로그인·공유·작업 보호를 유지합니다. Master/User 두 업데이트 ZIP이며 별도 Setup은 제공하지 않습니다.
