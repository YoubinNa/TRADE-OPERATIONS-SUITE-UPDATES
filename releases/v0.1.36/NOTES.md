# Master / User v0.1.36 Beta

- Master/User v0.1.36 Beta를 같은 앱·8개 모듈·업무 기준의 한 배포 단위로 제공합니다.
- User 아모비나 상단의 중복 작업 안내를 제거했습니다. Master 안내와 하단 펼침·접기 도움말은 유지합니다.
- Master/User 월간리포트 사이드바의 TRADE OPERATIONS / Glass Workspace와 Global Trade Operations Team 제목을 제거했습니다.
- 전체 8개 모듈과 PSR KR/VN 내부 화면의 카드·버튼·입력창·글꼴·색상을 공통 Glass Workspace로 정리했습니다.
- 기존 계산 기준·미완료 보류·파일 처리·메일 권한 차이와 입력/처리 중 작업 보호는 유지합니다.
- Master/User 기존 설치본은 프로그램 안에서 같은 버전으로 업데이트합니다. 최초 설치용 단일 Setup도 양쪽 함께 제공합니다.
- 두 ZIP과 두 Setup을 한 서명 요청으로 연결하며 전달 후 양쪽 검증을 통과해야 같은 업데이트 목록을 활성화합니다.
- Windows 자동 검증과 사용자 PC 적용·Microsoft Excel 자체 표시/재계산 확인은 구분합니다.
