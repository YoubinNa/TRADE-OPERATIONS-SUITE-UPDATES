# Master / User v0.1.101 Beta

- 최신 버전의 전체 필수 파일 목록과 PC 파일을 대조해 변경되거나 없는 파일만 내려받습니다. 같은 OCR·모듈·실행환경 파일은 재사용합니다.
- 중간 버전을 건너뛴 PC에도 과거 배포에서 추가된 필수 파일을 함께 받아 최신 실행본 전체를 완성한 후 적용합니다. 실패 시 기존 버전·설정·업무자료를 유지합니다.
- 기존 클라이언트가 새 업데이트 기능으로 처음 전환할 때는 전체 패키지가 한 번 필요합니다. Master/User 동일 버전으로 적용하며 기존 모듈 기능과 UI를 유지합니다.
