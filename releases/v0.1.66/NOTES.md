# Master / User v0.1.66 Beta

- Master/User v0.1.66 공동 업데이트입니다. 승인된 R2 공통 화면과 모듈 탐색 개선을 반영했습니다.
- 메인 상단 높이와 좌측 메뉴 간격을 줄이고 탭 안내 문장·작업 탭 개수를 삭제했습니다. 모든 배율과 창 크기에서 가용 너비에 맞춰 화면을 확장합니다.
- 모듈 진입 시 큰 상단 영역을 숨기고 기존 메인 복귀 줄 위치에 작업 탭을 배치합니다. 업무 메뉴 → 메인화면 → 모듈 탭 순서입니다.
- 메인화면은 메뉴 고정, 모듈 화면은 메뉴 숨김이 기본입니다. 두 화면의 고정 상태를 별도로 유지하며 왼쪽 압정으로 다시 고정할 수 있습니다.
- 메인 카드의 모듈 열기가 복귀 후 비활성화되던 문제를 수정했습니다. Backspace·Alt+왼쪽 화살표는 기존 복귀 경로로 입력·선택 파일·계산 결과와 탭을 유지하며 메인화면으로 이동합니다. 입력칸의 글자 삭제는 유지됩니다.
- 기존 업무 엔진·계산·판정·권한·파일 검증·전송 정책 및 설정·결과·저장 인증·캐시는 유지합니다. 탭 닫기·프로그램 종료·업데이트 시 기존 작업 보호가 적용됩니다.
