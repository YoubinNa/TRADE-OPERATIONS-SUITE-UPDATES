# Master / User v0.1.44 Beta

- Master/User v0.1.44 Beta 업데이트를 함께 제공합니다.
- PSR 계산기 R12: EVFTA 섬유 중량·가액 경로 확대, 한국산 직물 조건부 누적 및 일부 특수 BOM 검토를 반영했습니다.
- CPTPP 제품별 FIFO 예약 백업 JSON 미리보기·빈 장부 복원 및 저장 원장 대조를 제공합니다. 기존 기록 충돌·중복 차감·재고 초과를 방지하며 원본의 보류 조건을 유지합니다.
- PSR 예약 백업 JSON 다운로드와 Windows 파일 저장·복원 연결을 개선했습니다.
- 업무기록 연결 인증정보를 자동 갱신합니다. Master/User 모두 별도 키 입력 없이 기록 조회·공유 기능을 사용하도록 구성했습니다.
- 앞으로도 매 업데이트에 유효한 업무기록 저장소 전용 인증정보를 포함합니다. 기존 설정이 없는 PC도 자동 설정하며 이전 버전 복구 시 최신 저장 키와 업무 자료를 보존합니다.
- 회사별 당일 수행 상태와 연결 실패 표시를 구분하며 기존 검증 결과를 유지합니다.
- 업데이트 적용 후 프로그램을 재시작합니다. 이번 배포에는 별도 신규 설치용 Setup이 없습니다.
