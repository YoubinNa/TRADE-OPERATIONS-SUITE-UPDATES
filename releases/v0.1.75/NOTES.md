# Master / User v0.1.75 Beta

- 최신 취합 원본과 승인 과부족 원본을 법인별 최신 한 세트로 보관하여, 오프라인에서도 마지막 저장 파일·현황판을 사용할 수 있습니다.
- 동일 자료는 재다운로드하지 않으며 새 자료 검증 후 이전 원본과 캐시를 교체합니다. 수신·검증 실패 시 기존 정상본을 유지하고 개인 폴더 사본은 보존합니다.
- Master/User 모든 모듈 카드의 버전·지침 문구를 제거하고, Validation for Balance sheet 및 두 법인 수책재고취합의 현황 버튼을 안쪽 여백을 유지해 오른쪽에 정렬했습니다.
