# Master / User v0.1.102 Beta

- 현황판은 화면 폭에 맞춰 4열로 표시하고 카드 전체 영역을 누르면 해당 모듈이나 현황이 열립니다. 완료/미완료와 현황 확인 표시는 유지하며 물류비 웹사이트 버튼·즐겨찾기·재고 보조 기능을 보존합니다.
- 확인 요청 메일 발송 현황 창을 확대하고, 두 법인의 주간·월간 최신 발송 기록과 실제 첨부 공유용 HTML을 Master/User가 열 수 있게 연결했습니다. 이번 버전 이후 저장된 첨부부터 제공하며 업로드 실패는 메일 재발송 없이 재시도합니다.
- 기존 업무 모듈과 자료를 보존하며 최신 필수 파일 목록으로 변경·누락된 파일만 받습니다. 정상 v0.1.101 기준 다운로드는 Master 약0.64MB, User 약0.62MB이며 목록 정보가 추가됩니다. 오래된 버전은 필요한 누적 파일을 함께 받으며 구형 업데이트 방식은 전체 패키지가 필요할 수 있습니다.
