# Master / User v0.1.70 Beta

- Master/User v0.1.70 공동 업데이트입니다. 최종 저장된 PSR R88·승인 UI-v8과 세관 검수비용 대조 개정본을 반영했습니다.
- PSR에 검증 완료한 AIFTA 직접법과 R88 보완 내용을 연결했습니다. 직접법 비용 입력, 35% 경계값, 필수 입력 누락 차단 및 결과 Excel 저장을 확인했습니다.
- PSR의 입력·결과 화면, 자재별 검토·합산 대상 필터·Excel 구성과 한국어·영어·베트남어를 유지합니다. 진행 중인 후속 변경은 포함하지 않았습니다.
- 세관 검수비용 대조는 7개 필수 항목을 입력하고, 일반 검수 예상 비용과 UTM을 포함한 선택 방식 총비용 및 차액을 비교합니다. 입력 변경 시 기존 결과를 해제하며 언어 전환과 작업 탭 복귀 시 결과를 보존합니다.
- 메인화면의 업무 카드 4개를 같은 너비로 배치하고, 마지막 베트남 물류비용 카드는 기본 브라우저에서 연결합니다. 기존 수책재고 취합·권한·설정·인증·저장 자료 및 업데이트 복구 기능을 유지합니다.
