# Master / User v0.1.35 Beta

- Master / User v0.1.35 Beta — 동일한 앱·8개 모듈·업무 기준을 함께 제공합니다.
- PSR 지정 인계본 반영: BOM Excel 양식 다운로드·선택 업로드·드래그 드롭·직접 수정·재계산, KR/VN 공통 UI 및 HS 앞 2자리 추천.
- 기존 계산 기준과 미완료·판정 보류 조건을 유지합니다. KR 비율 계산을 품목별 PSR 확정 판정으로 확대하지 않습니다.
- 메인 복귀 버튼·Backspace·Alt+←의 작업 보호를 공통 적용합니다. 메인 복귀는 예/Enter, 종료·업데이트 확인은 아니요가 기본입니다.
- User는 업무에 필요한 안내를 유지하고 관리·개발 이력 안내와 Master 전용 메일 기능을 제외합니다.
- 기존 Master는 프로그램 내부에서 온라인 업데이트하며, User 최초 설치는 User Setup 단일 파일을 사용합니다. 기존 설정·기록·업무 자료를 보존합니다.
- 두 업데이트 패키지와 두 Setup은 한 서명 요청으로 연결합니다. 서명 전달 후 양쪽 검증을 통과해야 같은 배포 목록을 활성화합니다.
- Windows 자동 검증과 실제 사용자 PC 인수를 구분합니다. Microsoft Excel 자체 표시·재계산과 새 User PC 인수는 후속 확인 대상입니다.
