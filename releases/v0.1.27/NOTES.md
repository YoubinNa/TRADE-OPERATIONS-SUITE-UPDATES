# Master v0.1.27 — 세관 검수비용 대조 활성화

- 업무 도구의 세관 검수비용 대조를 실행할 수 있습니다.
- 확정된 개별 모듈 0.1.2의 AIR/SEA-LCL/SEA-FCL 계산·입력 방식·MODE별 입력 유지·초기화·허용오차·과소 청구 적합 판정·3개 언어를 유지합니다.
- 기존 Glass Workspace, 고정 헤더, 배율, 작업 보호를 유지합니다.
- 기존 번역·재고·메일·대조 모듈 기준은 변경하지 않습니다. PSR 계산기는 개발 중으로 유지합니다.
- v0.1.26에서 프로그램 내 온라인 업데이트로 적용합니다. 별도 설치파일 재설치는 필요하지 않습니다.

원본과 Master/User 각각81개 사례의 결과·판정·오류 표시 일치 및 Windows 업데이트/복구 검증을 완료했습니다. 실제 사용자 PC의 v27 업무 확인은 적용 후 별도입니다.
