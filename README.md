# TRADE OPERATIONS SUITE — Updates

TRADE OPERATIONS SUITE의 공식 업데이트 배포 전용 저장소입니다.

**현재 상태: 배포 채널 준비 중. 공개 업데이트 파일은 아직 게시하지 않았습니다.** 저장소 생성만으로 기존 프로그램의 업데이트 연결이 변경되지는 않습니다.

준비가 완료되면 프로그램에서 최신 승인 버전을 확인하고 다운로드·적용할 수 있습니다. 이용자에게 GitHub 계정이나 토큰, 별도 로그인·PC 등록을 요구하지 않습니다. 최초 설치 이후 일반 업데이트에는 별도 설치파일 실행을 요구하지 않는 것을 목표로 합니다.

이 저장소에는 검사를 마친 배포 파일, 버전 정보, 공개용 변경 안내, 서명·해시 및 필요한 제3자 라이선스 고지만 게시합니다. 개발 이력과 내부 자료를 공개하는 저장소가 아닙니다. 파일의 공개 배포가 별도 오픈소스 라이선스 부여를 뜻하지 않으며, 포함된 제3자 구성요소에는 각 라이선스가 적용됩니다.

공식 배포·변경 권한은 저장소 소유자가 관리합니다. 프로그램은 승인된 배포 파일의 서명과 무결성을 확인하도록 전환할 예정입니다. 서명 검증은 이용자 인증이 아니며 Windows 게시자 인증/SmartScreen 보증을 의미하지 않습니다.
