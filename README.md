# TRADE OPERATIONS SUITE — 공개 업데이트 배포

**현재 활성 온라인 업데이트: Master v0.1.21.** 기존 앱 전환 목록은 순번 4, v0.1.21부터 이용하는 장기 목록은 순번 5입니다.

- 1920×1080 기준 Glass Workspace와 해상도별 배치.
- 50~200% 확대/축소, Ctrl +/−/0, 배율 기억과 100% 복원.
- 공통 창·메뉴·확인/경고·업데이트·복구 화면.
- 기존 업무 기준, 선택 저장, 비차단 알림과 메일 제목 편집 유지.

기존 Master는 **최신 여부 확인 → 업데이트 다운로드 → 적용·재시작**으로 갱신합니다. 별도 Setup, GitHub 로그인이나 토큰 입력은 필요하지 않습니다. v0.1.17 이전 설치본은 기존 전환 경로가 필요합니다.

기존 운영 키의 두 서명과 Windows 운영 실행파일의 공개 다운로드·적용·복구·업데이트 이력 이관 검증을 통과했습니다. **v0.1.21 사용자 PC 적용·Windows 11 창 효과·실제 키보드/DPI 확인은 대기**입니다. PC에서 확인된 이전 버전은 v0.1.20입니다. User 정식 배포와 공개 최초 설치용 Setup은 아직 제공하지 않습니다.

개인 메일 설정·양식은 기존 PC에 보존하며 공개 패키지에 포함하지 않습니다. 이 저장소에는 검사한 배포 파일과 공개용 버전 정보·서명·해시·제3자 라이선스만 게시합니다. 공개 배포가 별도 오픈소스 라이선스 부여를 뜻하지 않으며 제3자 구성요소에는 각 라이선스가 적용됩니다.
