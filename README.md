# TRADE OPERATIONS SUITE — Updates

TRADE OPERATIONS SUITE의 공식 업데이트 배포 전용 저장소입니다.

**현재 상태: 활성 서명 목록은 Master v0.1.17. v0.1.19 공개 업데이트 검증 후보를 별도 제공합니다.** v0.1.19는 서명·적용 검증 전이며 활성 업데이트가 아닙니다. 공개 설치파일과 User 정식 배포는 아직 없습니다. 기존 Master 프로그램은 기존 배포 경로의 전환 업데이트를 먼저 적용해야 이 공개 채널을 사용합니다.

v0.1.17 전환본은 이 저장소의 서명된 목록에서 최신 승인 버전을 확인합니다. 공개 패키지의 다운로드·적용은 패키지 검토와 후속 검증 후 제공됩니다. 이용자에게 GitHub 계정이나 토큰, 별도 로그인·PC 등록을 요구하지 않습니다. 최초 설치 이후 일반 업데이트에는 별도 설치파일 실행을 요구하지 않는 것을 목표로 합니다.

이 저장소에는 검사를 마친 배포 파일, 버전 정보, 공개용 변경 안내, 서명·해시 및 필요한 제3자 라이선스 고지만 게시합니다. 개발 이력과 내부 자료를 공개하는 저장소가 아닙니다. 파일의 공개 배포가 별도 오픈소스 라이선스 부여를 뜻하지 않으며, 포함된 제3자 구성요소에는 각 라이선스가 적용됩니다.

공식 배포·변경 권한은 저장소 소유자가 관리합니다. v0.1.17은 실행파일에 고정된 공개키로 배포 목록의 서명을 검증합니다. 이후 공개 패키지를 제공할 때 크기·해시·호환성 및 적용 직전 서명도 검증합니다. 서명 검증은 이용자 인증이 아니며 Windows 게시자 인증/SmartScreen 보증을 의미하지 않습니다.
