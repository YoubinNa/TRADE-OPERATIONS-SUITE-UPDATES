# Master 서명 요청 메타데이터

current-request.json은 Master용 서명 도우미가 읽는 공개 데이터입니다. 현재 v0.1.23은 서명·배포·PC 확인을 완료하여 state=idle이며 다시 서명할 필요가 없습니다.

다음 승인 배포의 Windows 검사와 공개 내용 검사를 마친 후 정확한 payload·SHA-256·공개용 변경 개요만 ready 요청으로 기록합니다. 신규 요청의 만료는 2099-12-31 23:59:59 UTC여야 합니다. 개인키·자격증명·메일 자산·업무 자료·내부 시험 로그를 넣지 않습니다.

요청은 실행 코드가 아니며 서명되지 않은 검토 데이터입니다. Master가 내용을 확인하고 PC의 기존 키로 명시적으로 서명한 뒤, 운영 서명/다운로드/적용 검증을 거쳐 업데이트 목록에 게시합니다. 요청 등록만으로 자동 서명하거나 배포하지 않습니다. User의 업데이트 경로는 기존 updates/stable-longterm.signed.json입니다.
