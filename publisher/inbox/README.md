# Master 서명 결과 자동 수신함

서명 도우미 v1.1.0이 승인된 공개 서명 결과만 저장합니다. 파일명은 `seq-<순번>-<payload SHA256>.signed.json`입니다. 같은 파일은 덮어쓰지 않으며 재전송 시 동일 내용을 확인합니다.

이 폴더 저장은 활성 업데이트 게시가 아닙니다. 배포 담당자는 현재 요청과 일치하는 파일을 직접 읽어 운영 공개키·payload·승인 패키지와 기존 Windows 검증을 확인하고 승인 범위에서 게시합니다. Master에게 결과 복사·추가 배포 승인 절차를 반복 요구하지 않습니다. 개인키·토큰·개인 설정·업무 문서는 업로드하지 않습니다.
