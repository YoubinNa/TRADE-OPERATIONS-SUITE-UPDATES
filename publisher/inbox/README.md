# Master 서명 결과 자동 수신함

도우미 v1.1.1은 승인된 공개 서명 결과를 `seq-<순번>-<payload SHA256>.signed.json`에 자동 저장하고 다시 읽어 확인합니다. 같은 파일은 덮어쓰지 않으며 동일 결과는 다시 쓰지 않습니다. 현재 순번9 파일은 이미 공개된 v24 서명을 이용한 실제 전달 검사의 결과이며 새 배포나 재서명이 아닙니다.

배포 담당자는 현재 요청과 일치하는 파일을 직접 읽어 운영 공개키·payload·승인 패키지·Windows 검증 후 승인 범위에서 게시합니다. 같은 결과의 수동 전달이나 배포 승인을 반복 요청하지 않습니다. 파일 수신은 활성 목록 변경과 구분합니다. 개인키·토큰·업무 문서는 저장하지 않습니다.
